# Testimonial formats

Four shapes that a screen recorder can produce. Pick one and commit — mixing
them produces a video that is a tour again.

## Workflow Proof — the default

The customer narrates their own routine in the first person while that exact
routine runs on screen. Start on the state before the product does its work,
show the one action that changes everything, land on the result.

Use it when there is a repeated task with a visible outcome. It is the
format that best exploits what ndemo has and a video model does not: the
screen is real, so the claim is checkable.

Three segments is usually enough — *what it used to be*, *the moment*, *the
proof*. A fourth is normally a feature that wandered in.

## Split Journey — the comparison

Two passes, one after the other: the old way, then the same job with the
product. Not side by side — ndemo records one viewport, so the contrast is
sequential.

Strongest when the old way is genuinely tedious and you are willing to show
it in real time. The temptation is to speed through the painful half; don't.
The waiting **is** the argument. If the manual route takes forty seconds of
clicking, forty seconds of clicking is what sells the alternative.

Use it when the product replaces a process rather than adding a capability.

## Data Proof — the result on screen

Open on the finished artifact — the populated dashboard, the reconciled
ledger, the clean extracted output — and let the narration explain what it
took to get there before. The screen carries the claim; the voice supplies
the contrast.

Use it when the outcome is visual and self-evident. Weak when the result is
a number the viewer has no baseline for: "47 discrepancies" means nothing
unless the narration says how many used to slip through.

## Montage Proof — breadth

Four to six short segments, one capability each, cut fast under continuous
narration. It trades depth for coverage.

Use it sparingly. A montage says "this product does many things", which is a
product-demo claim, not a testimonial. It works as the middle third of a
longer piece, rarely as the whole.

## Choosing

| The story is about… | Format |
|---|---|
| a routine that got shorter | Workflow Proof |
| a process that got replaced | Split Journey |
| an output that speaks for itself | Data Proof |
| adoption across a team | Montage Proof |

If two fit, take the one with fewer segments. A testimonial that overstays
stops being a testimonial and becomes a demo with a person's name attached.
